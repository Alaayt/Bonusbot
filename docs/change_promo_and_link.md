# دليل تعديل البروموكود ورابط التسجيل

كل الإعدادات الحساسة (البروموكود، رابط التسجيل، رابط التطبيق) تأتي من متغيرات بيئة **وليست مكتوبة داخل الكود** - هذا يسمح بتغييرها دون أي نشر جديد للكود.

## تغيير البروموكود

1. عدّل `PROMO_CODE` في ملف `.env`:
   ```
   PROMO_CODE=NEW_CODE_HERE
   ```
2. أعد تشغيل البوت (`docker compose restart bot` أو أعد تشغيل عملية `python -m app.main`).
3. البروموكود سيظهر تلقائيًا في كل رسائل التسجيل (`app/bot/handlers/registration.py` يقرأه من `settings.promo_code`، ولا يوجد أي مكان آخر في الكود مكتوب فيه `VIP10IQ` بشكل ثابت خارج بيانات JSON التاريخية لكل عرض التي تعكس ما كان ساريًا وقت المراجعة).

⚠️ لاحظ: حقل `promo_code` داخل كل ملف `data/promotions/<slug>.json` هو **نسخة توثيقية** لما كان البروموكود وقت المراجعة، وليس المصدر الفعلي الذي يعتمد عليه البوت وقت الرد على المستخدم - المصدر الفعلي دائمًا هو `PROMO_CODE` في `.env`.

## تغيير رابط التسجيل

```
AFFILIATE_REGISTRATION_URL=https://your-real-affiliate-link.example
```

بدون هذا المتغير، البوت **لن يخترع رابطًا بديلاً أبدًا** - سيعرض البروموكود فقط ويطلب من المستخدم التواصل مع المدير (حسب `registration_link_missing` في ملفات `app/locales/*.py`).

## تغيير رابط تحميل التطبيق

```
APP_DOWNLOAD_URL=https://your-app-download-link.example
```

## تغيير قائمة المشرفين (Admin IDs)

```
ADMIN_IDS=123456789,987654321
```
قائمة Telegram User ID مفصولة بفواصل، بدون مسافات. احصل على ID أي مستخدم عبر بوتات مثل [@userinfobot](https://t.me/userinfobot).
