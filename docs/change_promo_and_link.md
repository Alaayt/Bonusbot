# دليل تعديل البروموكود ورابط التسجيل

كل الإعدادات الحساسة (البروموكود، رابط التسجيل، رابط التطبيق) تأتي من متغيرات بيئة **وليست مكتوبة داخل الكود** - هذا يسمح بتغييرها دون أي نشر جديد للكود.

## تغيير البروموكود

⚠️ **تحديث مهم**: خلافًا لما كان موثّقًا هنا سابقًا، البروموكود **ليس** مقروءًا ديناميكيًا من `PROMO_CODE` في كل مكان بالبوت - جزء منه نص ثابت مكتوب حرفيًا. لازم تحدّث **كل** الأماكن التالية يدويًا عند تغييره:

1. `PROMO_CODE` في `.env` (وفي إعدادات البيئة على منصة النشر مثل Railway) - هذا هو المصدر اللي يقرأه فعليًا:
   - `app/bot/handlers/registration.py` (رسائل التسجيل)
   - `app/ai/client.py` (سياق الذكاء الاصطناعي عند الرد الحر)
   - `app/promotions/services/formatter.py` (سطر "🎟 البروموكود" اللي يظهر بشرح كل عرض)
2. **نصوص ثابتة** لازم تُعدَّل يدويًا بالبحث والاستبدال (البروموكود القديم مكتوب حرفيًا داخلها، ما يتحدّث تلقائيًا):
   - `app/locales/ar.py`, `app/locales/en.py`, `app/locales/fr.py` - عدة رسائل تذكر البروموكود صراحة (الترحيب، `existing_account_needs_new_one`، `has_account_reply`، إلخ).
   - `app/ai/prompts/system_identity.md`, `persuasion.md`, `troubleshoot.md` - الـ System Prompt يذكر البروموكود كنص ثابت للذكاء الاصطناعي.
   - `app/bot/handlers/missing_bonus.py` - نص افتراضي (hypothesis) عن نسيان إدخال البروموكود.
   - حقل `"promo_code"` داخل **كل** ملف `data/promotions/<slug>.json` - يُدرَج بالكامل ضمن سياق الذكاء الاصطناعي (`_promotion_context_block` في `app/ai/client.py` يُصدِّر بيانات العرض كاملة كـ JSON)، فلو تُرك قديمًا قد يربّك النموذج بوجود رقمين مختلفين للبروموكود بنفس الرد.
3. أعد تشغيل البوت (`docker compose restart bot`، أو أعد النشر إذا كنت على Railway).

نصيحة عملية: أسهل طريقة لتطبيق هذا بأمان هي بحث نصي شامل عن البروموكود القديم عبر المشروع (باستثناء `data/raw_sources/` التي تبقى سجلًا تاريخيًا لما استُلم فعليًا وقتها ولا تُعدَّل) واستبداله بالجديد.

## تغيير رابط التسجيل

```
AFFILIATE_REGISTRATION_URL=https://your-real-affiliate-link.example
```

بدون هذا المتغير، البوت **لن يخترع رابطًا بديلاً أبدًا** - سيعرض البروموكود فقط ويطلب من المستخدم التواصل مع المدير (حسب `registration_link_missing` في ملفات `app/locales/*.py`).

## تغيير رابط تحميل التطبيق

```
APP_DOWNLOAD_URL=https://your-app-download-link.example
```

## تغيير قائمة المشرفين (Admin IDs)

```
ADMIN_IDS=123456789,987654321
```
قائمة Telegram User ID مفصولة بفواصل، بدون مسافات. احصل على ID أي مستخدم عبر بوتات مثل [@userinfobot](https://t.me/userinfobot).
